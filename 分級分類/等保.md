我国**网络安全等级保护**（等保 2.0，依据 GB/T 22240-2020《网络安全等级保护定级指南》）将等级保护对象共划分为 **5 个安全保护等级**，级别越高，安全防护要求和监管越严格。

### 等保（一至五级）

| 等级     | 名称        | 受到破坏后的危害程度                                                          | 典型应用场景 / 示例                             | 等级测评 |
| ------ | --------- | ------------------------------------------------------------------- | --------------------------------------- | ---- |
| **一级** | **自主保护级** | 对**公民、法人及其他组织的合法权益**造成**一般损害**                                      | 小型企业内部办公网、一般非敏感小型静态展示网站。                | /    |
| **二级** | **指导保护级** | 对**合法权益**造成**严重/特别严重损害**；<br><br>或对**社会秩序和公共利益**造成**一般损害**，不损害国家安全。 | 一般企业 ERP/OA 系统、地方性中小型政务/商业服务平台。         | 两年一次 |
| **三级** | **监督保护级** | 对**社会秩序和公共利益**造成**严重损害**；<br><br>或对**国家安全**造成**损害**。                | 地市级以上核心政务系统、金融支付系统、公立医院核心系统、大型电商/互联网平台。 | 一年一次 |
| **四级** | **强制保护级** | 对**社会秩序和公共利益**造成**特别严重损害**；<br><br>或对**国家安全**造成**严重损害**。            | 国家级关键基础设施（如电网、广播电视传输网、电信核心网、中央部委核心系统）。  | 半年一次 |
| **五级** | **专控保护级** | 对**国家安全**造成**特别严重损害**。                                              | 国家极端核心的涉密或国防领域系统（实际工作中非公开，由国家专门机构管理）。   |      |
