
|                                    | **Virus（電腦病毒）**                                                           | **Worm（電腦蠕蟲）**                                                 |
| ---------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **檔案角度**<br><br>  <br><br>（是否修改檔案） | **可感染**（檔案）<br><br>  <br><br>會將惡意程式碼注入並修改正常的檔案或系統區塊，使正常檔案變質。              | **不感染**（檔案）<br><br>  <br><br>不會去修改或寄生在其他正常檔案內，只是單純將自己複製並傳送出去。  |
| **存在方式**                           | **依附性**<br><br>  <br><br>無法單獨存在，必須**依附**於宿主檔案（如 `.exe`、`.docx` 或開機區）才能運作。 | **獨立性**<br><br>  <br><br>具備完全的**獨立性**，本身就是一個完整的獨立程式，不需要任何宿主檔案。 |
| **執行條件**                           | 需要人類行為觸發（如執行**被依附**的檔案）。                                                  | 利用網路漏洞自動執行與擴散，無需人類操作。                                          |
| **傳播範圍**                           | 隨被**感染**的檔案被複製、分享而傳播。                                                     | 利用網路在連網設備之間自主蔓延。                                               |
| **傳播速度**                           | 較慢，受限於使用者分享檔案或點擊的頻率。                                                      | 極快，可在短時間內利用網路感染大量連網設備。                                         |
| **主要危害**                           | 修改或破壞檔案、偷竊資料、損毀系統設定。                                                      | 消耗大量網路頻寬造成癱瘓（DDoS）、開後門、破壞系統服務。                                 |
| **知名案例**                           | ILOVEYOU 病毒、CIH 病毒。                                                       | WannaCry（想哭勒索蠕蟲）、Stuxnet（震網）、Conficker。                        |



### 精簡記憶口訣：
- **Virus（病毒）**：具**依附性**，**可感染**檔案。
- **Worm（蠕蟲）**：具**獨立性**，**不感染**檔案。
