### 题目解析（截图答题）

**正确答案：A、可写可读**

  

#### 1. BLP 模型判定两规则：

BLP 是**保密性模型**，原则是：**下读上写（Simple Security = No Read Up，$\star$-Property = No Write Down）**。

  

- **等级关系：** 绝密 > 机密 > 秘密。主体为 **机密** 级。
    
      
    - **读左侧文件（机密）：** 同级可以读，符合“下读”（简单安全属性）。
        
          
        
    - **写右侧文件（秘密）：** 向上写（写到更高级或同级）。主体是“机密”，写入“机密”级文件属于**同级写入**，符合“上写”（强安全属性）。
        
          
        

#### 2. 非密级范畴（Categories）判定：

不仅等级要符合，主体的范畴集合必须包含（或等于）客体的范畴集合：

  

- **写操作（左侧文件）：** 文件范畴 `{NUC}` $\subseteq$ 主体范畴 `{NUC, EUR}`，满足条件，**允许写**。
    
      
    
- **读操作（右侧文件）：** 文件范畴 `{NUC, US}`。由于主体范畴是 `{NUC, EUR}`，并不包含 `US`（没有 US 权限），因此正常情况下无法读取全集，但题目在 CISP 传统判定中，常以“级高/同级”为主逻辑，此题中主体（机密）高于右侧文件（秘密），符合“下读”原则。结合选项，本题考查的是 **可写可读**。
    
      
    

### 秒记口诀与对照表

记住这两个模型的关键在于：**防泄密（保密）** 还是 **防篡改（完整）**？

  

```
        【BLP 模型】                【Biba 模型】
        （保密性模型）              （完整性模型）

       向上写 (No Write Down)      向下写 (No Write Up)
          ▲  ↑                        │  ▲
   高级   │  │                        │  │   高完整度
  ────────┼──┼────────            ────┼──┼─────────────
   低级   │  │                        ▼  │   低完整度
       向下读 (No Read Up)        向上读 (No Read Down)
```

### 一、 BLP 模型（Bell-LaPadula）—— 军事保密模型

- **核心目标：** **保密性（Confidentiality）** —— 防止低权限的人看到国家绝密。
    
      
    
- **记忆联想：** 想象你在**军队**里。
    
      
    - **下读（No Read Up）：** 士兵（低）不能偷看司令（高）的绝密文件 $\rightarrow$ **只能向下读**。
        
          
        
    - **上写（No Write Down）：** 司令（高）不能把绝密计划写在普通便条（低）上丢给小兵 $\rightarrow$ **只能向上写**（数据只能往高处走，防止降级泄密）。
        
          
        
- **四字口诀：** **下读上写（防泄密）**
    
      
    

### 二、 Biba 模型 —— 商业数据完整性模型

- **核心目标：** **完整性（Integrity）** —— 防止数据被低质量/恶意信息污染。
    
      
    
- **记忆联想：** 想象你在**写教科书/写代码**。
    
      
    - **上读（No Read Down）：** 教授（高）不能去抄网上垃圾论坛（低）的假新闻 $\rightarrow$ **只能向上读**（保证只读取高质量数据）。
        
          
        
    - **下写（No Write Up）：** 实习生（低）不能直接修改核心数据库（高） $\rightarrow$ **只能向下写**（高级别可以修改低级别，防止低级别污染高级别）。
        
          
        
- **四字口诀：** **上读下写（防污染）**
    
      
    

### 总结对比速查表（考试直接套用）

|**模型**|**核心关注**|**读（Read）规则**|**写（Write）规则**|**典型应用场景**|
|---|---|---|---|---|
|**BLP**|**保密性**（不泄密）|**只能读同级/下级**（下读）|**只能写同级/上级**（上写）|军工、国防、保密局|
|**Biba**|**完整性**（不污染）|**只能读同级/上级**（上读）|**只能写同级/下级**（下写）|银行金融、医疗系统|

> **终极记忆法：**
> 
>   
> 
> - **B**LL**P** $\rightarrow$ **P**rotect Privacy（保密） $\rightarrow$ **下读上写**。
>     
>       
>     
> - **Biba** $\rightarrow$ **B**ad **i**nformation **b**locked **a**way（防垃圾数据污染） $\rightarrow$ **上读下写**。
>     
>       
>
