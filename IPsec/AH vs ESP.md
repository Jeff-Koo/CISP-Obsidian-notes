### IPsec 两大核心安全协议（AH vs ESP）

| **维度**        | **AH (Authentication Header)**  | **ESP (Encapsulating Security Payload)** |
| ------------- | ------------------------------- | ---------------------------------------- |
| **IP 协议号**    | **51**                          | **50**                                   |
| **机密性（数据加密）** | **不支持**（明文传输）                   | **支持**（对数据载荷加密）                          |
| **完整性与身份认证**  | 支持                              | 支持                                       |
| **防重放攻击**     | 支持                              | 支持                                       |
| **校验保护范围**    | 包含外层 IP 头在内的**整个报文**            | 仅包含 ESP Header 之后的数据及 ESP Trailer        |
| **NAT 穿透兼容性** | **不兼容**（NAT 修改 IP 头会导致 AH 校验失败） | **兼容**（可通过 NAT-T 机制穿透）                   |
| **应用现状**      | 因不支持加密且与 NAT 冲突，**极少单独使用**      | **IPsec VPN 的主流核心选择**                    |

IPsec 的两大核心协议 **AH（认证头协议）** 和 **ESP（封装安全载荷协议）**，均可以与 **传输模式（Transport Mode）** 和 **隧道模式（Tunnel Mode）** 自由组合搭配使用。
