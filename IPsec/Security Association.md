> 歸屬：[[IPsec]]

1. **安全关联（SA, Security Association）：**
    - SA 是单向的逻辑连接。一对通信双向至少需要建立 **2 个 IPsec SA**。
    - 由 **三元组** 唯一标识：`三元组 = SPI（安全参数索引） + 目的 IP 地址 + 安全协议号（50/51）`。

2. **地址聚合优化：**
    - 每匹配一条“感兴趣流（ACL）”就会协商建立一对 SA。
    - 在分支机构规划 IP 地址时，使用**可聚合的 IP 地址段**，可以把多条细分子网流量合并匹配同一条策略，显著**减少 SA 的数量与系统资源消耗**。
