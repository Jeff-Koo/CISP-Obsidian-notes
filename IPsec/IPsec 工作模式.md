### IPsec 的两种工作模式

```
[ 传输模式 (Transport Mode) ] 
┌───────────┬────────────┬────────────────────────┐
│  原 IP 头  │ IPsec 头   │  TCP / UDP + 数据载荷   │
└───────────┴────────────┴────────────────────────┘
                         |<----- 保护/加密范围 ---->|

[ 隧道模式 (Tunnel Mode) ] 
┌───────────┬────────────┬───────────┬────────────┬────────────────────────┐
│  新 IP 头  │ IPsec 头   │  原 IP 头 │ TCP / UDP  │       数据载荷         │
└───────────┴────────────┴───────────┴────────────┴────────────────────────┘
                         |<----------------- 保护/加密范围 --------------->|
```

- **传输模式（Transport Mode）：**
    - 不改变原 IP 报文头，仅在原 IP 头与上层载荷之间插入 IPsec 头（AH/ESP）。
    - **应用场景：** 端到端（Host-to-Host）的主机间直接安全通信。

- **隧道模式（Tunnel Mode）：**
    - 会生成全新的**外层 IP 报文头**，将包含原 IP 头在内的整个原始数据包完全隐藏/加密封装在内。
    - **应用场景：** 网关到网关（Site-to-Site VPN）或客户端到网关（Remote Access VPN），是企业 VPN 最常用的模式。

### IPsec 模式对比速记表

| **维度**     | **传输模式 (Transport Mode)** | **隧道模式 (Tunnel Mode)**                      |
| ---------- | ------------------------- | ------------------------------------------- |
| **保护范围**   | 仅保护 **IP Payload**        | 保护 **整个原始 IP 数据包（IP Header + Payload）**     |
| **IP 头处理** | 保留原 IP 头                  | 隐藏原 IP 头，叠加 **新 IP 头（New IP Header）**       |
| **典型场景**   | 主机到主机（Host-to-Host）直接加密通信 | 站点到站点（Site-to-Site / Gateway-to-Gateway）VPN |
