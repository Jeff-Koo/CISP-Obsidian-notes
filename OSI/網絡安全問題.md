## 安全問題



| **攻擊方向**               | **網路層（Network Layer）(關注：路由、IP 位址、封包轉發)**                                                                                 | **傳輸層（Transport Layer）(關注：連線、管道、封包流)**                                                     | **應用層（Application Layer）(關注：業務邏輯、使用者身份、資料內容)**                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **阻斷服務 (DoS)**         | **Smurf Attack**, Ping of Death, ICMP Flood (IP / ICMP), Teardrop 攻擊<br><br><br><br>_(網路邊界頻寬 (Bandwidth)、路由器/防火牆封包處理能力)_ | **TCP SYN Flood**, UDP Flood<br><br><br>  <br><br>_(消耗伺服器的 TCP 連線資源/記憶體)_                  | **HTTP Flood**, Slowloris, XML/JSON Bomb, Long URL Attack<br><br><br><br>_(消耗 API/資料庫/CPU 解析資源)_             |
| **欺騙 (Spoofing)**      | **IP Spoofing**, ARP Spoofing<br><br><br><br><br>_(冒充封包的來源 IP 位址)_                                                       | **TCP Spoofing**, TCP Reset Injection<br><br>  <br><br>_(冒充傳輸對端的 IP/Port，強行中斷連線)_          | **Credential Stuffing**, Cookie / Session Spoofing, DNS Spoofing<br><br><br><br>_(冒充合法使用者的 Session 或 Token)_ |
| **竊聽 (Eavesdropping)** | **IP Packet Sniffing**<br><br><br><br><br><br>_(被動截取經路由轉發的 IP 封包)_                                                       | **Packet Sniffing** (如 Wireshark 抓未加密 TCP/UDP 流量)<br><br><br><br>_(看得到連線傳輸的原生封包)_          | **Man-in-the-Middle (MitM)** / API Sniffing<br><br><br><br>_(解析明文 HTTP/FTP/SMTP 傳輸的憑證與敏感資料)_                 |
| **偽造 (Forgery)**       | **ICMP Redirect Attack**<br><br><br><br><br>_(偽造路由重導向封包，劫持流量路徑)_                                                         | **TCP Sequence Number Prediction / Injection**<br><br><br><br>_(偽造合法的 TCP 序號插入惡意封包)_       | **CSRF** (跨站請求偽造), SQL Injection 注入偽造查詢<br><br><br><br>_(利用合法使用者的權限發送偽造的業務請求)_                               |
| **暴力破解 (Brute Force)** | **Ping Sweep / Network Sweep**<br><br><br><br><br>_(探測存活主機與網段邊界)_                                                        | **Port Scanning**, TCP Sequence Number Brute-forcing<br><br><br>_(爆破開放的 Port 或嘗試猜測連線狀態參數)_ | **Password Spraying**, Credential Brute-forcing<br><br><br><br><br>_(爆破登入頁面的帳號密碼、API Key)_                   |


特別提
**Ping of Death**：惡意巨型 ICMP 封包，重組時記憶體溢位
**Teardrop**：刻意（Fragment Offset）互相重疊（Overlapping），重組到喊
**Smurf Attack**：放大攻擊，誘使LAN Hosts 回傳 ICMP Echo 回應惡意，塞爆受害者的網路頻寬
**ICMP Flood**：海量的 ICMP Echo，塞爆受害者的網路頻寬
**SYN Flood**：利用 TCP 3-Way Handshake，大量發送 SYN 封包但不發送 ACK 封包
